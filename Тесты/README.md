# Тесты

Автоматическая проверка приложения перед выкладкой на сайт.

## Как запустить

Двойной клик по **ПРОВЕРИТЬ.bat**

Первый запуск попросит установить Node.js, если его нет — ссылка будет
прямо в окне. Дальше всё работает само.

В конце будет один из двух ответов:

- **ВСЁ ХОРОШО** — можно обновлять сайт
- **ЕСТЬ ПРОБЛЕМЫ** — внизу список, что именно сломалось

## Зачем это нужно

Приложение растёт, и правка в одном месте может незаметно сломать другое.
Каждая проверка здесь — это баг, который уже был найден и исправлен:
тест не даёт ему вернуться.

Сейчас проверок: **102**. Что они покрывают:

| Раздел | Что проверяется |
|---|---|
| Даты в выписках | Русские, английские и американские форматы дат |
| Суммы в выписках | Разные разделители, валютные символы, минусы |
| График рассрочки | Число месяца не съезжает, долг гасится полностью |
| Минимальный остаток | Значение сохраняется и не сбрасывается |
| Категории | Нет тех, что приводили к двойному учёту платежей |
| Прогноз | Учитываются операции с начала месяца, а не только с сегодня |
| Подсказка «С чего начать» | Шаги гаснут по мере заполнения |
| Счета с операциями | Раскрытие, быстрый ввод, привязка импорта к счёту |
| Переводы | Не искажают доходы и расходы |
| Правила категорий | Срабатывают везде, «ё» и «е» равнозначны |
| История капитала | Считается на прошлые даты без будущих операций |
| Свой платёж за месяц | Уменьшенная сумма гасит долг частично, график продолжается дальше |
| Свой платёж — ручной график банка | Правка суммы работает и во вставленном графике, не только в авторасчёте |

## Когда запускать

Отдельно запускать обычно не нужно: **ОБНОВИТЬ САЙТ.bat** прогоняет
эти тесты сам — после сборки, но до отправки на сайт.

Если тесты не прошли, выкладка отменяется, и на сайте остаётся
предыдущая рабочая версия. В окне будет список того, что сломалось.

Запускать **ПРОВЕРИТЬ.bat** вручную стоит, когда хотите проверить
правки, ещё не выкладывая их.

## Если Node.js не установлен

Обновление сайта всё равно сработает — тесты просто пропустятся
с пометкой `SKIPPED`. Но лучше поставить: это единственное,
что страхует от незаметных поломок.

## Служебные файлы

После первого запуска здесь появятся `node_modules` (библиотека
для тестов) и `результат.txt` (отчёт последнего прогона).
Трогать не нужно, на GitHub они не выгружаются.
