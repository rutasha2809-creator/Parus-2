# Парус — личные финансы

Веб-приложение для учёта личных финансов: доходы и расходы, платёжный
календарь с прогнозом кассовых разрывов, графики погашения кредитов,
аналитика с выделением необязательных трат.

**Открыть:** https://rutasha2809-creator.github.io/Parus-2/

---

## Возможности

- Счета всех типов: карты, наличные, вклады, кредитные карты, кредиты, долги
- Импорт банковских выписок из CSV, Excel и PDF с автоматической категоризацией
- Платёжный календарь: прогноз остатка на каждый день, подсветка кассовых разрывов
- Графики погашения: аннуитет по ставке или загрузка графика банка,
  учёт фактических платежей и досрочного погашения
- Кредитные карты: льготный период, процент минимального платежа,
  сравнение сценариев погашения
- Аналитика: структура расходов, обязательные и необязательные траты
- Работает без интернета, устанавливается на телефон
- Синхронизация между устройствами, вход по ссылке на почту

## Устройство

`index.html` собирается из шести модулей в папке `Исходники`:

| Файл | Отвечает за |
|---|---|
| `01-shell.html` | разметка, стили, экраны |
| `02-core.js` | хранилище, счета, операции, категории |
| `03-debts.js` | кредиты, графики погашения, льготный период |
| `04-import.js` | импорт выписок |
| `05-calendar.js` | календарь, прогноз, аналитика |
| `06-sync.js` | профиль, вход, синхронизация |

Правки вносятся в модули — `index.html` перезаписывается при сборке.

## Публикация

Двойной клик по `ОБНОВИТЬ САЙТ.bat`: соберёт, спросит описание изменения
и отправит на GitHub. Сайт обновится за минуту.

Первый раз нужно один раз запустить `НАСТРОИТЬ ОДИН РАЗ.bat`.
